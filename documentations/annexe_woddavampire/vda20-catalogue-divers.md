## 1. Archétypes (Nature et Attitude)

L'**Attitude** n'a aucun effet de règle. La **Nature** indique comment le personnage regagne de la Volonté (+1, parfois plus au choix du MJ). « Bête » est exclu de la liste jouable.

| Archétype | Regain de Volonté (Nature) |
|---|---|
| Architecte | Fonder quelque chose d'important ou de durable |
| Autocrate | Exercer son contrôle sur un groupe ou une organisation |
| Bon vivant | Vraiment prendre du plaisir (une fête mémorable peut rapporter plus) |
| Bravache | Obtenir ce qu'on veut par la brutalité physique ou sociale, ou l'intimidation |
| Protecteur (Caregiver) | Protéger ou soigner quelqu'un avec succès |
| Fervent (Celebrant) | Servir sa cause ou y convertir quelqu'un |
| Caméléon | Duper quelqu'un en se faisant passer pour un autre, à son profit |
| Enfant | Convaincre quelqu'un de l'aider sans contrepartie |
| Compétiteur | Triompher dans une situation dramatique (plus si la victoire est difficile) |
| Conformiste | Le groupe ou le chef soutenu atteint un but grâce à son aide |
| Intrigant | Manipuler quelqu'un pour qu'il agisse contre son intérêt |
| Épouvantail (Creep Show) | Quelqu'un recule d'horreur ou de peur devant lui |
| Grincheux | Quelqu'un échoue exactement comme il l'avait prédit à voix haute |
| Dilettante | Trouver un nouvel engouement et abandonner complètement l'ancien |
| Défenseur | Défendre sa cause avec succès |
| Déviant | Bafouer les conventions sans en subir les conséquences |
| Énigme | Une action incompréhensible se révèle fructueuse |
| Œil du cyclone | Un tumulte ou un chaos éclate autour de lui |
| Fanatique | Accomplir quelque chose qui sert directement sa cause |
| Galant | Impressionner quelqu'un |
| Gourou | Ses conseils poussent quelqu'un à un acte éclairé inhabituel |
| Idéaliste | Une action rapproche son idéal de sa réalisation |
| Bouffon | Remonter le moral de malheureux, ou ridiculiser un tyran |
| Juge | Résoudre un problème par l'examen des preuves, ou réunir des parties opposées |
| Solitaire | Accomplir seul quelque chose qui profite à la coterie |
| Martyr | Subir un dommage ou une perte pour ses idéaux ou pour autrui |
| Masochiste | Sa souffrance lui rapporte un gain concret, ou une douleur inédite |
| Mercenaire | Réussir une vente, quelle qu'elle soit |
| Monstre | Commettre une atrocité précise (le MJ limite ce regain, par exemple aux tests de dégénérescence) |
| Pédagogue | Voir quelqu'un profiter de la sagesse qu'il a partagée |
| Pénitent | Obtenir l'absolution d'un péché |
| Perfectionniste | Son exemple pousse quelqu'un à réussir |
| Philosophe | Une approche logique résout un problème, ou un savoir logique resservir ailleurs |
| Rebelle | Ses actions nuisent à l'opposition qu'il s'est choisie |
| Canaille (Rogue) | Son égoïsme lui rapporte un profit |
| Sadique | Infliger de la douleur pour son seul plaisir |
| Soldat | Atteindre l'objectif de ses ordres |
| Survivant | Survivre à une menace par pure ténacité, ou faire tenir quelqu'un |
| Casse-cou (Thrill-Seeker) | Réussir une tâche dangereuse entreprise délibérément |
| Traditionaliste | La méthode éprouvée s'avère la meilleure, ou une position défendue se révèle sage |
| Tyran | Guider un groupe dans une tâche difficile |
| Visionnaire | Convaincre d'autres de croire en sa vision de l'avenir |

## 6. Dérangements

**Règles** (`spec_woddavampire.md` §19) : déclenchés par le stress (tout ce qui appelle un jet de Maîtrise/Instinct), effet pour la nuit ; 1 Volonté = 1 tour de lucidité. Effets ci-dessous pour les vampires (pour les mortels, au jugement du MJ).

| Famille | Dérangement | Effet |
|---|---|---|
| Dyscrasie (maladie du corps) | Mélancolique | −1 à toutes les réserves ; −1 diff à toute frénésie |
| | Flegmatique | −1 dé aux jets d'Astuce et de Dextérité |
| | Sanguin | Le MJ tire 3 Capacités : +1 diff avec elles ; +1 diff à tous les jets d'Attributs mentaux |
| | Colérique | +2 diff pour résister à la frénésie ; −1 diff aux actes de violence douloureuse |
| Courroux divin (malédiction de l'esprit) | Compulsion | Rituel obsessionnel ; empêché, −3 dés à tous les jets de frénésie (et frénésie plus souvent provoquée) |
| | Lunatisme | Lune croissante/pleine : −1 diff aux actions prolongées, +1 diff contre la frénésie ; lune décroissante : léthargie ; nouvelle lune : Volonté réduite de moitié (arrondi supérieur) et +1 sang pour se lever |
| | Mal sacré | Au déclenchement, Vigueur diff 8 ; échec : crise convulsive dans les 3 tours, pour la scène ; −1 dé aux jets physiques le reste de la nuit |
| | Danse de Saint-Guy | Mouvements involontaires, fièvre, larmes de sang : +2 diff aux jets sociaux ; peut se propager à un groupe |
| Péchés de l'âme (souillure de l'âme) | Animisme sanguinaire | Croit boire l'âme de ses victimes, qui lui parlent ; doit leur répondre à voix haute (difficultés sociales variables) |
| | Visions | Voit des figures saintes l'exhorter : −2 dés aux jets de dégénérescence |
| | Voix | Paranoïa démoniaque : +1 diff aux jets sociaux ; un échec critique social (de part ou d'autre) provoque une frénésie de peur |

## 8. Goules (PNJ, non jouables)

- Ne vieillissent pas tant qu'elles ont du sang de vampire ; sans gorgée mensuelle, perdent leurs pouvoirs et rattrapent leur âge.
- Réserve max **10** (+1 par siècle), dépense 1 point par tour ; se soignent et boostent leurs Attributs physiques comme un vampire ; peuvent régénérer un membre (1 à 3 sang + 1 Volonté + Vigueur diff 8 ; échec critique : perte définitive).
- Guérissent comme des mortels (ou par le sang) ; absorbent le létal, le contondant comme des mortels.
- 1 point de **Puissance** après chaque gorgée. Célérité, Force d'âme et Puissance toujours accessibles ; autres Disciplines selon le domitor. 1er niveau : 20 XP ; niveaux suivants : 25 × valeur (15 × pour les Disciplines de clan du domitor).

- Avec au moins 5 points de sang du domitor : faiblesse de son clan ; peut entrer en frénésie (−2 diff pour résister).
- Manque : après un mois, Maîtrise diff 7 pour ne pas boire à chaque occasion ; puis envie de sang humain (Volonté diff 6 ou 1 Volonté ; échec critique : doit consommer chair ou sang humain).
- Goules animales : réserve selon la taille (humain 10, grand chien 6, paresseux 4, cheval 14) ; seulement Célérité, Force d'âme, Puissance.

## 10. Démons et esprits (PNJ, résumé)

Quatre traits :
- **Volonté** : Volonté, actions de Dextérité et d'Astuce ; réserve de défense.
- **Rage** : actions de Force et de Vigueur ; réserve d'attaque.
- **Gnose** : jets mentaux et la plupart des jets sociaux ; sert de Perception.
- **Essence** : en général la somme des trois autres ; alimente les Charmes et sert de santé. À 0, l'esprit se dissipe et ne peut revenir au même endroit avant cent ans (sauf magie noire ou tourment prolongé).

Exemples de démons du livre : non retranscrits (p. 401 et suivantes, non lues en entier).

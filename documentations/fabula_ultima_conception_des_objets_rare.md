#  Conception des objets rares

Lors de la création d'un objet, le Meneur de jeu peux soit choisir un objet rare existant, soit en créer un nouveau à partir d'un objet de base. Pour ce faire, il peut y ajouter diverse modification dont une qualité. Une liste des qualités par défaut est fourni par le livre de base.

## 1.Liste des qualités par défaut du livre de base

Toutes les qualités ont un type. Les qualités **défensives** peuvent être appliqués sur n'importe quel type d'objet, les qualités **offensives** peuvent être appliqués seulement sur les armes et les qualités **d'amélioration** peuvent être appliqués sur les armures et les accessoires .

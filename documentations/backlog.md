# Backlog

Backlog consolidé avec le MJ le 2026-10-18, versionné dans le dépôt depuis le 2026-11-12. À relire quand il demande « la todo ». Ne garde que ce qui reste à faire : un item terminé et parti en prod passe dans `backlog_fait.md` (tri après chaque release).

Pour qu'il ne se périme pas entre deux bilans :
- une spec ou un document se cite par son **nom seul** (`spec_genmap.md`), jamais par son chemin ;
- pas de décompte ni de liste de fichiers qui bougent avec le code (« recopié dans plusieurs slugs », pas « dans 4 slugs ») : le bilan vérifie dans le code ;
- l'état du dépôt (commits hors prod, fichiers en cours) se lit dans Git, pas ici ;
- un bilan relit chaque item contre le code avant de le présenter, et le chantier qui touche un item met le backlog à jour dans son commit.

# Combat

## Déroulé du tour

- **Initiative** : chacun tire son initiative ; on agit dans l'ordre décroissant.
- **Attaque** : à son tour, le personnage agit ou attaque. Il peut retarder son action ou céder son tour.
- **Défense** : une défense peut intervenir à tout moment ; elle est déclarée avant le jet d'attaque.
- **Dégâts** : l'attaque réussie donne un jet de dégâts, puis la cible lance son absorption.
- Les actions supplémentaires (actions multiples) se résolvent en fin de tour.

## Initiative

- **Valeur d'initiative** = Dextérité + Astuce + Célérité.
- **Initiative du tour** = valeur + 1d10 − malus de blessure − pénalité d'armure.
- Égalité : la valeur d'initiative la plus haute agit d'abord ; égalité parfaite : actions simultanées.

## Attaque

| Type | Réserve | Portée |
|---|---|---|
| Mains nues | Dextérité + Bagarre | 1 m |
| Arme de mêlée | Dextérité + Mêlée | 2 m |
| Arc, arbalète, fronde | Dextérité + Archerie | Portée de l'arme |
| Arme de jet | Dextérité + Athlétisme | Portée de l'arme |

- Difficulté 6 de base, modifiée par l'arme et les circonstances.
- Portée : normale jusqu'à la portée de l'arme, +1 difficulté jusqu'au double, +2 jusqu'au triple, impossible au-delà.

## Défenses

Déclarée avant le jet d'attaque ; ses succès sont retirés à ceux de l'attaquant.

| Défense | Réserve | Remarque |
|---|---|---|
| Blocage | Dextérité + Bagarre | Contondant uniquement, sauf Force d'âme ou armure adaptée |
| Esquive | Dextérité + Athlétisme | +2 difficulté contre les flèches (la Célérité active l'annule) |
| Parade | Dextérité + Mêlée | Contre une attaque à mains nues, l'excédent de succès devient une attaque contre l'agresseur |

**Défense totale** : le personnage renonce à agir ; réserve complète contre la 1ʳᵉ attaque, puis −1 dé cumulatif par défense suivante, sans pénalité de difficulté.

## Complications

| Complication | Effet |
|---|---|
| Aveuglé | +2 dés pour l'attaquer ; +2 difficulté à toute action demandant la vue (défenses comprises) |
| Membre estropié | +2 difficulté aux actions utilisant ce membre tant que les blessures restent |
| Sonné | Dégâts après absorption supérieurs à la Vigueur (mortel) ou à Vigueur + 2 (vampire) : perd son tour suivant |
| Immobilisé | Tenu : +2 dés pour l'attaquer ; totalement immobilisé (ligoté, empalé) : touché automatiquement, dégâts = réserve sans jet |
| Renversé | Se relever : Dex + Athlétisme difficulté 6 ; échec = action perdue ; réussite = −2 à l'initiative au tour suivant |

## Dégâts et absorption

- **Dégâts** = valeur de l'arme + succès nets de l'attaque ; difficulté 6 ; chaque succès = 1 niveau de santé.
- **Absorption** (jet réflexe, difficulté 6, toujours possible) : Vigueur + Force d'âme + armure, selon le type de dégâts (voir Santé et dégâts).
- Les jets de dégâts et d'absorption ne peuvent pas échouer critiquement.
- **Armure** : sa valeur s'ajoute à l'absorption ; sa pénalité s'applique à l'initiative et aux actions basées sur la Dextérité.
- **Perforant X** : retire X dés d'armure.
- **Viser une faille** : +2 difficulté à l'attaque, l'armure est ignorée.
- Une armure est détruite si le jet de dégâts atteint le double de sa valeur.
- Le feu et le soleil ignorent l'armure.

## Combat monté

- Le cavalier utilise les Attributs de sa monture pour les actions de combat.
- +1 dé de dégâts par tour d'élan (5 au maximum).
- La monture peut faire une défense par tour (souvent une esquive) sans coûter d'action.
- Le cavalier ne peut pas utiliser plus de points de Capacité que ses points d'Équitation.
- Dextérité + Équitation pour rester en selle en situation tendue.

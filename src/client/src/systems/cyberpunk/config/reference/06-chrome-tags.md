# Chrome, chips et tags

## Le chrome
Les implants donnent des capacités augmentées et permettent souvent de lancer **Synth** à la place d'une autre stat. Leurs tags sont **narratifs** : ils décrivent des états ou des capacités, sans effet automatique. Le MC décide quand un tag négatif entre en jeu.

## Chrome et humanité
Le coût humain du chrome passe par les **tags négatifs** et par **+aliénant**, pour ce qui remplace ou efface quelque chose d'irrémédiablement humain. Pas de stat d'Humanité, pas de jet automatique : le MC active +douloureux, +dégradation, +aliénant, +défaillant dans les moments de tension.

## Acheter du chrome en jeu
Cred, un charcudoc (move *Passer sur le billard*), parfois un jet. Selon le prix, c'est du neuf (très cher), de l'occasion, ou du matériel de provenance douteuse qui arrive avec des tags négatifs. Les prix de création ne s'appliquent plus.

## Chips et prises
Le socle lit **une chip à la fois**. Une chip de compétence donne **+1 continu** tant qu'elle est insérée ; une chip de comm permet de communiquer par la tête. Porter deux chips demande une **Prise supplémentaire**.

## Console et daemons
La console du Netrunner (Cyberconsole intégrée ou deck externe) a une **mémoire interne** qui stocke ses **daemons**, affichée sur la fiche (**2** de base, extensible avec du chrome : +slots mémoire). Une **chip daemon** est limitée en utilisations ; **Extraire des données** peut la copier dans la mémoire de la console, pour un usage illimité dans la limite de la capacité.

## Tags de capacité

| Tag | Signification |
|---|---|
| +anti-flash | Protège des effets visuels assommants |
| +amplification lumineuse | Voir correctement en faible luminosité |
| +atténuation | Protège des effets soniques assommants |
| +brouillage | Brouille les communications non cryptées |
| +crypté | Résiste au piratage : le MC doit d'abord casser le cryptage |
| +enregistrement | Enregistre les données traitées |
| +gamme de fréquences | Entendre au-delà des limites humaines |
| +implant | Arme discrète, impossible à retirer sans dommages |
| +large capacité | Stockage important |
| +multitâche | Contrôle de plusieurs véhicules ou drones à la fois |
| +partition inaccessible | Mode messager : l'utilisateur n'accède pas aux données stockées |
| +relais satellite | Contrôlable à distance : souvent une porte dérobée corpo |
| +thermographique | Voit les émissions de chaleur |
| +vitesse élevée | Transfert et accès aux données très rapides |
| +zoom | Portée visuelle augmentée |

## Tags négatifs

| Tag | Signification |
|---|---|
| +douloureux | Douleur intense, dommages nerveux à terme |
| +dégradation | Fonctionne pour l'instant ; c'est une question de temps |
| +défaillant | Parfois, ça ne marche pas |
| +médiocre | Fonctionne, mais moins bien que prévu |
| +aliénant | Efface quelque chose d'humain : levier relationnel ou émotionnel |

## Conséquences
Blessures et états passent par des **tags narratifs** sur le personnage, sans jauge chiffrée (+blessé, +sonné, +grillé, +repéré, +endetté…). Ils se résolvent dans la fiction. Les tags **verrouillés** (cadenas) viennent des manœuvres et ne se retirent qu'en mode Édition.

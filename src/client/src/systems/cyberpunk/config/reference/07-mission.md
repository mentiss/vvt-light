# Mission

## Phases
1. **Acquisition** : obtenir le contrat, négocier les termes (*Obtenir le taf*).
2. **Recon** : préparation et information.
3. **Action** : exécution.
4. **Extraction** : sortie et gestion des conséquences.

Les phases guident la structure sans l'imposer.

## Horloges de mission
Chaque mission a au moins une **Horloge d'alerte** liée à la faction ciblée. Elle avance avec le bruit que font les opérateurs.

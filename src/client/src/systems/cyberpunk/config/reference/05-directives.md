# Directives et expérience

## Directives personnelles
Un moteur de comportement : quand le personnage agit en accord avec elle, même au détriment de la Mission, il gagne de l'**expérience**. Les trous ___ se complètent à la création.

| Directive | Déclencheur d'expérience |
|---|---|
| **Ambitieux** | Quand tu augmentes ton statut ou nuis au statut d'un rival au sein de ___ |
| **Célèbre** | Quand ton désir de célébrité attire une attention malvenue sur la Mission |
| **Compatissant** | Quand tu fais passer ta compassion pour les plus faibles avant la Mission |
| **Filial** | Quand tu fais passer les conseils de ___ avant la Mission |
| **Fureteur** | Quand tu découvres davantage d'informations à propos de ___ |
| **Intime** | Quand tu fais passer ton ami ___ avant la Mission |
| **Masochiste** | Quand tu subis une blessure significative |
| **Motivé** | Décris ton code de conduite. Quand le respecter entrave la Mission |
| **Partisan** | Quand ton adhésion à ___ entrave la Mission |
| **Prosélyte** | Quand tu persuades les autres d'agir selon tes croyances |
| **Protecteur** | Quand tu fais passer tes responsabilités envers ___ avant la Mission |
| **Prudent** | Quand tu résous une situation tendue sans violence |
| **Rejeté** | Quand ton ancienne appartenance à ___ entrave la Mission |
| **Trompeur** | Quand les mensonges sur ton identité ou ton passé compromettent la Mission |
| **Vénal** | Quand tu entraves la Mission pour saisir une opportunité de profit |
| **Vengeur** | Quand tu nuis à ___ ou à ses intérêts |
| **Violent** | Quand tu choisis la violence alors qu'une alternative existe |

## Directives de mission
**1 à 2** objectifs concrets à court terme : ce que le personnage veut accomplir maintenant. En accomplir une rapporte de l'expérience ; en fin de session, les directives accomplies sont remplacées, les autres peuvent être reformulées. Elles peuvent être partagées entre joueurs.

## Avancements
- **Avancement de base**, toutes les **10 XP** : un move de son playbook, ou +1 à une stat (max +2).
- **Avancements majeurs**, après **5 avancements de base** : +1 à une stat (max +3), racheter une menace ou une dette, reculer une Horloge de corporation d'un segment, un move d'un **autre playbook**. Une justification fictionnelle est toujours demandée.
- Changer de personnage ou de playbook : décision narrative, à la table.

# FAQ et glossaire

## Questions fréquentes

| Question | Réponse |
|---|---|
| Peut-on Se défendre, S'interposer ou Aider après avoir vu le jet ? | Oui. |
| Que peut-on utiliser en attaque d'opportunité ? | Toute attaque de mêlée à 1 action. Tout ce qui se greffe sur une telle attaque fonctionne normalement (Tactiques de combat, Opportuniste féroce, Attaque sournoise, Frénésie, dés de Jugement, dés de Furie, etc.). Pas de sort, pas de capacité à plus d'une action, pas de compagnon, pas de sbire (seulement les héros), pas d'agrippement (c'est un test de compétence). |
| Comment mettre fin à l'état effrayé ? | En dépensant une action pour une sauvegarde de VOL, ou (si le MJ l'accepte) par tout autre moyen logique : réussir un critique, voir la source de sa peur vous rater, l'Aide d'un allié. |
| Capacités défensives et réactions ? | Les réactions se résolvent avant leur déclencheur : si l'attaquant est désormais empoisonné, effrayé, aveuglé, etc., l'attaque est relancée avec le désavantage de cet état. Un seul sort défensif chaque fois que vous vous défendez (Bouclier de givre OU Alacrité, pas les deux dans le même round). |
| CLÉ dans un sort ? | C'est la caractéristique du lanceur, pas celle de la cible. |
| Créer une ouverture contre des dégâts fixes ou des d44, d66, d88 ? | Ces attaques n'ont pas de dé primaire : l'ouverture s'applique à la prochaine attaque qui en a un. Si la prochaine attaque fait naturellement un critique, vous pouvez reporter le +1 sur l'attaque suivante. |
| S'interposer contre une zone ? | Oui, si l'allié peut être poussé hors de la zone. |
| S'interposer contre une attaque conditionnelle (qui ne vise qu'une créature à terre, par exemple) ? | S'il est logique que le héros écarte son allié (qui n'est pas agrippé, par exemple), cela fonctionne normalement : le héros qui s'interpose subit les dégâts et les autres effets. |
| Agripper est-il une attaque ? | Oui. Tout ce qui nuit à vos ennemis est une attaque et subit les attaques précipitées (le test de compétence se fait alors avec désavantage). |
| Plafond d'actions ? | Des sorts et capacités comme Feu du cœur ou Électrocharge peuvent vous faire dépasser votre plafond normal d'actions. |
| Lien protecteur ? | Cela compte comme être attaqué : on peut Se défendre normalement. |
| Séduction (Entice) : alliés, effets multiplicateurs, zones ? | Oui, on peut séduire un allié. Les effets multiplicateurs (comme les dégâts doublés de Réprimande) multiplient aussi ces dégâts ; les zones portent aussi les dégâts supplémentaires. |
| Peut-on parer un critique avec son bouclier en dehors de la réaction Se défendre ? | Oui. |
| Un héros caché peut-il s'interposer ? | Oui, et l'attaque est lancée avec désavantage comme d'habitude. |
| Peut-on Se défendre contre les dégâts de chute ou de repoussé ? | Oui. |

## Glossaire

| Terme | Définition |
|---|---|
| **À terre** | Le déplacement coûte le double, désavantage aux attaques. Les attaques de mêlée contre vous ont l'avantage, les attaques à distance le désavantage. Se relever coûte 3 cases de Vitesse. |
| **Abri** | Presque entièrement caché : les attaques entrantes ont le désavantage. Entièrement caché (**abri total**) : ne peut généralement pas être ciblé. |
| **Action gratuite** | Ne coûte ni action ni autre ressource (mana…), sauf mention contraire. |
| **Agrippé** | Tenu par une autre créature ; les attaques contre l'un ou l'autre ont l'avantage. |
| **Allié** | Une créature amicale, autre que vous. |
| **Allonge X** | La zone dans un rayon de X cases autour d'un personnage, en cube ou en sphère au choix. |
| **Amplification** | Dépenser du mana supplémentaire sur un sort pour obtenir un effet de plus par mana supplémentaire. |
| **Assourdi** | N'entend pas. |
| **Attaque** | Toute action offensive : frapper avec une arme, lancer un sort nuisible, agripper, etc. |
| **Attaque de base** | Un tour de magie ou une attaque d'arme. |
| **Attaques précipitées** | Attaquer plus d'une fois par tour ajoute un désavantage cumulatif (la troisième attaque à l'épée courte du tour se lance à 3d6 en gardant le plus bas). |
| **Avantage X** | Lancez X dés supplémentaires et retirez les X plus bas (de gauche à droite en cas d'égalité). |
| **Aveuglé** | Ne voit pas. Les attaques contre vous ont l'avantage, et vos attaques ont le désavantage. |
| **Blessé** | A au moins une Blessure. |
| **Blessure** | Mesure de la proximité de la mort. En général, à 6, vous êtes mort. |
| **Caractéristiques** | FOR, DEX, INT, VOL : les attributs fondamentaux d'un personnage. |
| **Chargé** | Certains sorts et capacités ont des effets supplémentaires quand vous êtes chargé. Vous l'êtes dès que vous subissez des dégâts de foudre, pour 1 minute ou jusqu'à la fin du combat. |
| **Charmé** | Voit le charmeur comme un allié. Le charmeur a l'avantage dans ses interactions sociales avec vous. |
| **Chevaucher** | Vous vous déplacez avec la créature que vous chevauchez ; elle vous attaque avec désavantage, et les attaques qui vous ratent la frappent. |
| **Chute** | 1d6 dégâts par tranche de 2 cases de chute. |
| **Cible** | Une créature ou un objet choisi. Il doit être à Portée ou à Allonge, et perceptible. |
| **CLÉ** | Les deux caractéristiques les plus importantes d'une classe. Remplacez par l'une de vos caractéristiques clés. |
| **Concentration** | On ne se concentre que sur une chose à la fois. Sauvegarde de FOR DD 10 quand on subit un critique, sinon elle est rompue. |
| **Cône X** | Part du personnage et s'étend jusqu'à X cases, avec la même largeur à son extrémité. |
| **Coupable** | Une créature qui réussit un critique est coupable. |
| **Critique** | Quand une créature obtient le maximum sur son dé primaire, ce dé est relancé et ajouté au total. |
| **d44, d66, d88** | Lancez 2 dés identiques : le dé de gauche donne les dizaines, le second les unités. Ces attaques ne ratent pas et ne font pas de critique. |
| **Dé primaire** | Le dé le plus à gauche d'une attaque : il détermine si l'attaque rate ou fait un critique. |
| **Dégâts** | Perte de PV. Se défendre, perdre des PV temporaires, etc. ne comptent pas comme des dégâts infligés. |
| **Désavantage X** | Lancez X dés supplémentaires et retirez les X plus hauts (de gauche à droite en cas d'égalité). |
| **Distrait** | Une cible est distraite si elle est adjacente à un allié ou provoquée par lui, ou si elle ne peut pas vous voir. |
| **Effrayé** | Désavantage aux jets quand la source de la peur est proche ; Vitesse réduite de moitié en s'en approchant. |
| **Empoisonné** | Désavantage à tous les jets (en général, un soin y met fin). |
| **En sang** | À la moitié de ses PV ou moins. |
| **Entravé** | Toute créature dont les actions ou le déplacement sont réduits (étourdie, agrippée, immobilisée, à terre, ralentie, en terrain difficile). |
| **Étourdi** | Les héros perdent 1 action ; les monstres perdent leur déplacement OU 1 attaque lors de leur prochain tour. |
| **Évaluer** | Action pour analyser stratégiquement la situation en combat. |
| **Féroce** | Lancez 1 dé supplémentaire chaque fois que vous lancez des dégâts de critique. |
| **Focaliseur** | Peut remplacer la main libre pour lancer des sorts. |
| **Fouisseur** | Créature capable de se déplacer normalement sous terre. |
| **Fumant** | Aucun effet par lui-même, mais certains sorts et capacités ont des effets supplémentaires contre les créatures fumantes, et y mettent fin (par exemple Embrasement, Pyroclasme). |
| **Grimper** | Une créature dotée d'une Vitesse d'escalade se déplace sur les parois comme sur un sol plat ; sinon, grimper compte comme un terrain difficile. |
| **Immobilisé** | Ne peut pas se déplacer. Les attaques contre vous ont l'avantage. |
| **Incrémenter / décrémenter** | Utiliser un dé d'une taille au-dessus ou en dessous (d4 » d6 » d8 » d10 » d12 » d20). |
| **Invisible** | On ne peut pas vous voir. Vos attaques ont l'avantage, et les attaques contre vous ont le désavantage. |
| **Ligne X** | Ligne droite de X cases dans une direction. |
| **Mana** | Sert à lancer des sorts ; chaque classe indique comment elle en gagne. |
| **Mourant** | Un héros à 0 PV. |
| **Neutralisé** | Ne peut rien faire. Les attaques contre vous ont l'avantage, et les attaques de mêlée qui touchent sont des critiques. |
| **NIV** | Niveau. Dans une attaque, remplacez par le niveau du personnage. |
| **Non tenu** | Ni touché, ni porté, ni tenu par quiconque. |
| **Paralysé, sonné, inconscient** | Neutralisé. |
| **Pétrifié** | Neutralisé, avec tous les avantages et inconvénients d'un rocher ! Immunisé contre la plupart des dégâts, sauf grosses explosions, pioches et outils semblables. |
| **Points de compétence** | Servent à augmenter vos compétences ; vous en gagnez 1 à chaque niveau. |
| **Portée X** | Les attaques à distance ont le désavantage si UN SEUL ennemi est adjacent. La Portée peut être étendue. |
| **Provoqué** | Désavantage aux attaques, sauf contre le dernier à vous avoir provoqué. |
| **PV temporaires** | PV qui ne se reconstituent pas. |
| **Ralenti** | Vitesse réduite de moitié pendant votre prochain tour. |
| **Réduit au silence** | Ne peut ni lancer de sorts ni utiliser de capacités qui exigent de parler (par exemple les Ordres du Commandant). |
| **Rencontre** | Commence quand on lance l'initiative, se termine quand les hostilités cessent. |
| **Renforcé / affaibli X** | Dégâts d'attaque augmentés / réduits de X. |
| **Repos de terrain / repos sûr** | Prendre du temps pour récupérer une partie de ses ressources. |
| **Repousser X** | Déplacer de force une créature de X cases, en ignorant le terrain difficile. D'autres créatures ou l'environnement peuvent l'arrêter prématurément et lui infliger des dégâts. |
| **Résistance** | –10 dégâts contre un type de dégâts précis. |
| **Round** | Le temps pendant lequel chaque héros et chaque ennemi peut agir. |
| **Sbire** | Créature simple : tout dégât la tue ; chacun attaque avec un seul dé de dégâts, ne fait pas de critique et rate sur 1 ; quand plusieurs sbires attaquent une même cible, leurs dégâts s'additionnent et comptent comme une seule attaque. |
| **Se déplacer X** | Se déplacer jusqu'à X cases. |
| **Se téléporter** | Se déplacer instantanément. Ne provoque pas d'attaque d'opportunité. |
| **Surprise** | Quand le combat commence avant que tous les camps en aient conscience. |
| **Terrain difficile** | Vitesse réduite de moitié tant qu'on s'y trouve. |
| **Tour** | Le temps imparti à un héros ou à un groupe de monstres pour agir. |
| **Tour de magie** | Sort de base. Ne coûte pas de mana, et sa puissance augmente avec le niveau. |
| **Types de dégâts** | Contondant, perforant, tranchant, feu, glace, foudre, radiant, nécrotique et psychique. Les héros ne se soucient généralement pas du type des dégâts qu'ils subissent, mais certains monstres ou défis environnementaux, si. |
| **Vision aveugle X** | Vous percevez normalement créatures et obstacles à X cases, en ignorant l'état aveuglé, l'obscurité et l'invisibilité. |
| **Vulnérable** | +10 dégâts contre un type de dégâts précis. |
| **Zone** | Attaques spéciales qui visent une zone plutôt que des créatures précises. |

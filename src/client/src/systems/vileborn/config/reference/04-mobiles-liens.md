# Mobiles, liens, évolution

## Les mobiles

Deux mobiles, compatibles ou contradictoires, chacun avec sa case :
- l'**aspiration**, votre objectif personnel : quand elle s'applique à la situation, cochez-la pour guérir aussitôt une blessure ;
- le **devoir**, la tâche que l'ordre vous confie (au départ : *Achever votre formation*) : quand il s'applique, cochez-le pour guérir aussitôt un état.

Chaque mobile ne sert qu'une fois ; l'Obscurité décide quand il se renouvelle ou change. L'insécurité vous interdit vos mobiles.

## Les liens

Notez vos liens d'**affinité** ou de **rivalité** avec les autres Parias, et comment vous les ressentez. Le niveau du lien (−1, 0 ou +1) s'ajoute au jet quand vous agissez avec cette personne ou contre elle.

## Évoluer

Au fil de la formation, chaque Paria ajoute de nouveaux mots à sa personnalité et à sa formation, dans les cercles vides de sa fiche. Les autres évolutions (dés des approches, nouveaux dons, mobiles renouvelés) se décident avec l'Obscurité.
